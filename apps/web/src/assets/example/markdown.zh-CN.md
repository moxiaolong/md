# SoulStation 微信 Markdown 编辑器

欢迎使用 SoulStation 微信 Markdown 编辑器自用精简版。

## 基本用法

- 顶部菜单栏切换主题、字号、主题色等样式
- 编辑区直接输入 Markdown，右侧实时预览公众号效果
- 点击「复制」按钮，把渲染好的内容粘贴到公众号后台即可

## 支持的 Markdown 语法

- 标题、段落、列表、引用
- `行内代码`、代码块
- **加粗**、_斜体_、~~删除线~~
- 表格、链接、图片（本地图片自动转 Base64 内嵌）
- 脚注、任务列表

## 关于图片

本编辑器只支持本地图片上传：选择文件或粘贴时，图片会自动转换为 Base64 直接嵌入到 Markdown 中，不依赖任何第三方图床。粘贴 Markdown 文本中包含的外链图片 URL 保持原样，不会被下载或转存。
